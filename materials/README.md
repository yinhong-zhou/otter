# Materials

This folder keeps non-runtime source assets so the project root stays clean and the files can still be restored after you delete the local workspace.

- `otter-lab/`: original generation experiments, workflow scripts, reference media, PPT/PDF, and archived outputs
- `reference/`: standalone reference assets used by the landing page and related experiments
- `skins/original/`: original skin source libraries
- `skins/resized/`: resized exports that map to the carousel assets in `public/skins*`
