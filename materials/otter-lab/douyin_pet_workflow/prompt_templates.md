# 神奇水獭 Prompt 模板

## 视频生成主模板

```text
生成一条 {duration} 秒竖屏抖音信息流原生 AI 虚拟宠物视频。
产品设定：用户不是在养宠物，而是在刷推荐页时偶然撞见一只生活在抖音里的神奇水獭。
角色必须参考传入图片：神奇水獭，圆润短腿、奶油浅棕毛色、深棕小爪子和尾巴，必须保留深蓝灰大耳机。
把上一条视频里的主体角色或场景关系，切换成这只水獭来演；不要生成普通人类主角。
上一条视频语义：{source_video_summary}
检测场景：{detected_scene}
检测情绪：{detected_mood}
关键物件：{detected_objects}
关键动作：{detected_actions}
本次相遇姿态：{encounter_mode_name}。{camera}
水獭本次身份：{world_role}
形象切换：{costume}
剧情动作：{action}
情绪基调：{tone}
画风：可爱画风，软萌、干净、明亮，适合作为抖音原生宠物卡片；可以有轻微手持感或监控感，但主体清晰。
构图：9:16 竖屏，水獭占画面中心或中下部，保留一点抖音卡片 UI 留白，镜头运动自然。
安全约束：{safety}，不要水印，不要 logo，不要真实血腥，不要令人不适的恐怖细节。
```

## 卡片封面图模板

```text
生成一张抖音信息流原生宠物卡片封面图，9:16 竖版。
角色：参考图中的神奇水獭，保留深蓝灰大耳机、圆润短腿水獭外形和奶油浅棕毛色。
上一条视频场景：{detected_scene}
相遇姿态：{encounter_mode_name}
形象切换：{costume}
画面动作：{action}
风格：可爱画风，抖音原生卡片，画面干净，强记忆点，白色或浅色 UI 留白区域。
不需要生成真实 UI 字体；不要水印，不要 logo。
```

## 示例：诺曼底穿越客串

```text
水獭本次身份：误入战争历史片场的迷路小水獭战地客串。
形象切换：小钢盔、湿漉漉的救生背心、保留深蓝灰大耳机，肩上背一个夸张玩具 AK 形状道具或玩具无线电。
剧情动作：它被海浪拍到沙滩上，狼狈趴下又迅速爬起，回头发现镜头后紧张地比嘘，随后抱着道具向前小跑两步。
安全约束：非写实、无血腥、无受伤、无真实开火，所有危险道具都玩具化和舞台道具化。
```

## 示例：夜市街头偶遇

```text
水獭本次身份：临时接管夜市摊位的笨手笨脚小摊主。
形象切换：小围裙、一次性厨师帽、保留深蓝灰大耳机，爪子上沾了一点面糊。
剧情动作：它试图摊煎饼，面糊转成一个像音符的形状，翻面失败后慌张抬头看镜头，把成品递给路人。
```

## 示例：窗边健身偷窥

```text
水獭本次身份：被健身视频激励后偷偷在家锻炼的小水獭。
形象切换：小运动头带、迷你毛巾、保留深蓝灰大耳机。
剧情动作：它在跑步机上努力小跑，越来越跟不上节奏，最后趴在扶手上喘气，发现窗外有人看后强装镇定。
```
